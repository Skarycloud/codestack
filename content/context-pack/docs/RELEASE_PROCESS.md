# Release process

- Versioning: Semantic Versioning (MAJOR.MINOR.PATCH).
- Changelog: CHANGELOG.md, Keep a Changelog format.

## Checklist

1. All tasks for the release are done in TASKS.md.
2. CI green on main.
3. CHANGELOG.md updated; version bumped in [files].
4. Tag vX.Y.Z and create release notes.
5. Deploy (docs/DEPLOYMENT.md).
6. Announce in [channels].
